## 瀏覽器

面向 AI 智能體的瀏覽器自動化工具、MCP 伺服器及 AI 驅動瀏覽器。

- [chrome-devtools-mcp](https://github.com/ChromeDevTools/chrome-devtools-mcp) - 為編程智能體提供的 Chrome DevTools
- [playwright-mcp](https://github.com/microsoft/playwright-mcp) - Playwright MCP 伺服器
- [browser-use](https://github.com/browser-use/browser-use) - 使用瀏覽器的智能體。
- [steel-browser](https://github.com/steel-dev/steel-browser) - 🔥 為 AI 智能體及應用而設的開源瀏覽器 API。Steel Browser 是一個開箱即用的瀏覽器沙盒，讓你無需擔心基礎設施即可自動化網頁。
- [stagehand](https://github.com/browserbase/stagehand) - 用於擷取資料並與網絡上任何網站互動的 SDK。可配合 Claude Code、Codex、Eve、Mastra 等使用。
- [skyvern](https://github.com/Skyvern-AI/skyvern) - 使用 AI 自動化基於瀏覽器的工作流程
- [nanobrowser](https://github.com/nanobrowser/nanobrowser) - 用於 AI 驅動網頁自動化的開源 Chrome 擴充功能。使用你自己的 LLM API 金鑰執行多智能體工作流程。OpenAI Operator 的替代品。
- [computer-use-preview](https://github.com/google-gemini/computer-use-preview)
- [browsernode](https://github.com/lennybase/browsernode) - 🌐 讓網站可供 AI 智能體存取。輕鬆自動化線上任務。
- [glide](https://github.com/glide-browser/glide) - 一款可擴充且以鍵盤為核心的網頁瀏覽器
- [Scrapling](https://github.com/D4Vinci/Scrapling) - 🕷️ ️ 一個自適應的網頁擷取框架，由單次請求到全量爬取一應俱全！別害羞，加入我們：https://discord.gg/EMgGbDceNQ
- [BrowserOS](https://github.com/browseros-ai/BrowserOS) - 🌐 開源的智能體瀏覽器；ChatGPT Atlas、Perplexity Comet、Dia 的替代品。
- [agent-browser](https://github.com/vercel-labs/agent-browser) - 為 AI 智能體而設的瀏覽器自動化 CLI
- [browser](https://github.com/lightpanda-io/browser) - Lightpanda：為 AI 與自動化而設計的無頭瀏覽器
- [bb-browser](https://github.com/epiral/bb-browser) - 你的瀏覽器就是 API。為 AI 智能體提供 CLI + MCP 伺服器，讓其以你的登入狀態控制 Chrome。
- [pinchtab](https://github.com/pinchtab/pinchtab) - 高效能的瀏覽器自動化橋接與多實例編排器，具備進階隱身注入與即時儀表板。
- [carbonyl](https://github.com/fathyb/carbonyl) - 在終端機裡運行的 Chromium
- [web-access](https://github.com/eze-is/web-access) - 為 Claude Code 裝上完整聯網能力的 skill：三層通道調度 + 瀏覽器 CDP + 並行分治
- [browser-harness](https://github.com/browser-use/browser-harness) - Browser Harness | 自癒式框架，讓 LLM 能夠完成任何任務。
- [playwriter](https://github.com/remorses/playwriter) - 讓智能體控制你瀏覽器的 Chrome 擴充功能與 CLI。在有狀態的沙盒中執行 Playwright 程式碼片段。可作為 CLI 或 MCP 使用。
- [ladybird](https://github.com/LadybirdBrowser/ladybird) - 真正獨立的網頁瀏覽器
- [obscura](https://github.com/h4ckf0r0day/obscura) - 為 AI 智能體及網頁擷取而設的無頭瀏覽器
- [camofox-browser](https://github.com/jo-inc/camofox-browser) - 為 AI 智能體而設的隱身無頭瀏覽器 —— 繞過 Cloudflare、機器人偵測與反擷取。可直接替換 Puppeteer/Playwright。
